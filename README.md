# Sathish M R — DevOps Leadership Portfolio

This is a single-page portfolio designed for senior DevOps / SRE / Infrastructure / Platform Engineering leadership applications.

## Publish with GitHub Pages

1. Create a public GitHub repository named `sathish-mr.github.io`.
2. Upload `index.html` to the root of the repository.
3. Open GitHub → repository → Settings → Pages.
4. Select `Deploy from a branch`, choose `main` and `/root`, then Save.
5. Your portfolio will be available at:
   `https://sathish-mr.github.io/`
